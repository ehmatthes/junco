Junco is a demo custom coding harness for working with AI models. It lets the model interact with files within a project directory.

You can find a full writeup of this project at [Mostly Python](https://www.mostlypython.com/building-a-custom-harness/). You should read this series before running Junco, so you can make your own assessment of how effectively AI models are managed by the app.

Running Junco:

```sh
$ git clone https://github.com/ehmatthes/junco.git
$ cd junco
junco$ uv run junco --project-dir <path/to/project>
```
